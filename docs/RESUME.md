# 简历与面试讲解

## 可验证项目描述

**Privacy Relay — 面向模型流量的会话级隐私网关**  
技术栈：Python / FastAPI / SQLite / React / TypeScript / pytest / Playwright / GitHub Actions。

构建模型流量隐私网关，实现敏感实体检测、优先级重叠消解、会话内稳定令牌化、跨会话隔离与 TTL 撤销；密钥不可逆遮盖，并测试模型适配器仅接收脱敏输入与输出再检查。

English summary: An ephemeral privacy boundary with session-scoped stable tokens, irreversible secret redaction, TTL revocation and optional sanitized local-model relay.

## 讲解顺序

1. 先展示一个失败或攻击场景，说明受保护的资产与信任边界。
2. 运行成功与拒绝路径，展示 API 响应和原始证据。
3. 打开核心模块，解释算法、状态或事务如何保证约束。
4. 展示测试及真实限制，并提出下一步实验。

## 常见追问

### 为什么不同会话不能使用相同占位符？

稳定跨会话标识会增加关联追踪风险；随机会话隔离降低跨请求域关联能力，但不能消除上下文推断。

### 为什么密钥不允许恢复？

模型通常不需要密钥内容；对秘密执行不可逆遮盖降低意外回显风险，避免将恢复机制当作密钥传输通道。

### 如何支持多实例？

需要独立 vault、租户授权、加密存储、原子 TTL 与密钥轮换；当前进程内映射有意限制为单实例本地模式。

## 诚实使用

- 项目属于 AI 应用安全与 Agent 安全工程，不等同于大模型预训练、对齐或安全研究成果。
- 可以写真实实现和通过的测试数量；不能虚构用户量、生产 QPS、降低风险百分比或企业落地经历。
- 此初版使用 AI 辅助开发。亲自复现、修改并解释关键模块后再作为自己的面试项目展开。
- 性能或防御效果必须带上数据集版本、样本数、运行环境与测量方法。
